# 龙王子：顺序之门

可双击打开、完全离线使用的单文件互动课件。沿用原课件的五幅龙王子插画，以用户提供的《4s 第9讲.pdf》为题文依据。

范围截至 PDF 中第一次出现“课堂巩固”之前：18组原题、32个作答空、31个故事与教学场景。不含课堂巩固、入门测、能力提升；无配音。PDF 文件名写第9讲，内页标题写“第12讲 排列”，不据此改动题文和原题编号。

## 使用

- 在线版：<https://lanb46705-svg.github.io/dragon-prince-order/>
- 离线版：下载 [docs/index.html](docs/index.html)，保存后双击打开，无需网络。
- 点击目录跳转和搜索，左右方向键翻页，Home 回封面，Esc 关闭浮层或画笔。
- 答题核对、具体错因、提示、分步解析、知识小结和练习进度；可以撤销、重置和重新练习。
- 课堂画笔、可设置和暂停的倒计时、全屏；手机纵向显示支持滚动。

## 动手互动

| 内容 | 操作 |
| --- | --- |
| 龙晶试炼 | 自己发现顺序、反序比较、重复去重、预测总数；教师示例单独显示 |
| 排列与组合符号 | P/A/C 的取数在右上、总数在右下；自主填写连乘、调整参数、逐步展开 |
| 椅子与排队 | 点击或拖放，交换位置，检查有效方案并记录 |
| 相邻与插空 | 整组捆绑和拖动、交换内部顺序、向包括两端的不同空插入 |
| 选择限制 | 课程冲突、刀枪同选或同不选、组合不计反序、主客场与单循环比较 |
| 分段 | 巧克力与数位和：点击插板或撤板、即时显示每天数量或数字 |
| 图形与数字 | 点选三角形顶点、识别共线、按顺序选奇偶数字构造四位数 |

剧情、符号实验和方法演示标明为“课本外”或自由实验；不改变正式原题的数字。来源见 [reference/source.json](reference/source.json)。

高手挑战1的原解析漏算端点空，将576更正为960，课件中有明确说明；其余已收录答案均独立复算。

## 修改与构建

修改 `src/` 后构建，不直接手改生成的单文件：

```sh
python3 tools/build.py
python3 tools/check.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs
# 另一个终端执行浏览器回归（需安装 Playwright 和 Chromium/Chrome）
node tools/qa.mjs
```

`tools/qa.mjs` 的 Playwright 模块及 Chrome 路径目前为制作电脑的本机路径，在其他电脑运行时需相应调整。`tools/check.py` 不依赖第三方库，使用独立枚举和数学公式复算答案。

构建生成 `docs/index.html` 和本地 `output/龙王子_顺序之门_互动完整版.html`，两者内容相同。图片、样式、脚本全部内嵌；练习记录只保存在本浏览器，不上传。
